Open Studio ↗
  1. In Studio, dismiss the welcome tutorial if shown. Under Your Contracts, click the Import Contract icon (document with a down arrow, beside Upload).
  2. Paste the release address above into Contract Address, optionally name it ProtocolLens, then click Import. Studio retrieves the deployed source and attaches its methods. Do not use Deploy.
  3. Open Run and Debug (terminal icon in the left sidebar). Check Deployed at matches the release address. Keep Normal (Full Consensus) selected and transaction simulation off.
  4. Use the account shown in Studio’s top bar. Keep that same account for both commit_study and review. Only the record creator can initiate its review.

Troubleshooting & repeat attempts
Wrong contract, method or network: use the imported release at studio.genlayer.com. Not found or RPC error: check the hash and click Track again; do not resubmit the write. A timeout only stops polling and does not cancel the transaction. Finalized execution failure: inspect Studio’s error before retrying. “Only creator may request review”: select the original committing account. An INCONCLUSIVE decision is a completed review with insufficient evidence or model agreement; inspect its reason. The creator can call review again, up to three completed attempts per record. Each attempt remains visible.

A CHECK, WITH A TRAIL
Four questions.
Every change in context.
01 / OUTCOMES
Did the primary outcome move?
Check endpoint definitions, timing and primary versus secondary designations.
02 / ANALYSES
Was the planned analysis reported?
Identify omissions and distinguish explicit explanations from assumptions.
03 / POPULATION
Who was actually studied?
Compare eligibility and analysis populations against the committed protocol.
04 / SAMPLE SIZE
Where did the numbers change?
Look for recruitment shortfalls, exclusions and their stated reasons.
Uncertainty stays visible.
Outcomes are ALIGNED, EXPLAINED_CHANGES, DEVIATIONS or INCONCLUSIVE. Missing, altered or unreadable evidence cannot produce a clean result. Every completed review attempt remains in a hash-linked history.
