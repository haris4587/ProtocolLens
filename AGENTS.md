# ProtocolLens contributor guidance

## Visual identity

The user wants every GenLayer project to have a distinct visual identity. Avoid repeating the same palette, background, typography, hero composition and overall style across their projects. Choose a direction suited to each project's purpose; do not apply this project's dark theme as a universal template.

ProtocolLens uses a dark research-lab direction: ink-blue surfaces, electric-blue controls, coral deviation indicators, a technical comparison diagram and compact monospace labels. Preserve readable contrast, responsive layouts, keyboard focus indicators and reduced-motion support.

## Design-only changes

Preserve the deployed contract, Studio built-in signing workflow, transaction validation, finalized reads and receipt verification. Follow the Sites publishing workflow and preserve public access. Never claim visual browser verification when only build, DOM and RPC checks were performed.
